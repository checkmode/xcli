在小火箭中使用

  1. 打开「用户管理」，选择用户的「连接」按钮。
  2. 复制订阅地址，在小火箭中添加订阅；也可以直接扫描单个节点二维码。
  3. 更新订阅后选择所需入口，打开连接；使用 Hysteria 2 时客户端须支持该协议。
  4. 将「全局路由」设置为「代理」，避免规则将网站请求直接发出。

订阅地址和二维码包含访问凭据，请只交给对应用户。关闭小火箭后，设备会恢复原本的网络出口；是否阻止断线直连需在客户端设置。

NOTIFICATIONS

故障通知

未配置
支持通用 JSON Webhook。接收服务需接受 HTTPS POST；聊天机器人可能需要消息格式转换。地址与认证信息加密保存，读取页面时不会返回原文。

Webhook 配置

入口按独立探测结果计数；采集和核心按分钟检查。自动备份失败与恢复各通知一次。投递失败最多尝试 6 次。

当前故障

通知覆盖入口探测、探测结果中断、核心管理接口和本地自动备份。服务器完全离线时，需要外部监控才能主动通知。

接收服务与签名说明

消息包含事件编号、站点、故障／恢复类型、服务、发生时间和持续时间。不会发送用户凭据或访问记录。接收端应按事件编号去重。

启用签名后，X-Xcli-Signature 为 sha256= 加上 HMAC-SHA256 的十六进制值，签名内容为 X-Xcli-Timestamp、一个英文句点和原始请求正文。

“已投递”表示接收端返回 2xx。请发送测试后确认你最终使用的应用确实收到了消息。
