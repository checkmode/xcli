批量导入或直接编辑规则文本

每行：类型,内容,目标；IP 网段和 GEOIP 可附加 resolve 或 no-resolve。旧的三字段 IP 网段规则仍不额外解析。以 # 开头的行是注释，最多 500 条、14000 字节。
