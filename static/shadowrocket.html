哪些设置会改变？

DNS 随首页所选节点转发，关闭系统 DNS 与不支持 UDP 时的直连回退，并固定本服务器节点域名的解析地址。其他配置字段和规则保留。

上述步骤需要在小火箭中完成。页面无法读取安装结果或兼容模式状态；请确认模块已启用、兼容模式已关闭。停用模块可撤销 DNS 覆盖；兼容模式需在「设置 → 代理」中单独恢复，修改后重连 VPN。

Wi-Fi 下仍出现运营商 DNS？

即使网页出口是代理服务器，部分 DNS 查询也可能使用 Wi-Fi 侧的解析路径。确认兼容模式已关闭并重连后，保持同一 Wi-Fi、节点和全局代理模式，重新运行 DNS 泄漏扩展测试；不要沿用旧结果。

使用本指南的 DNS 模块时，应检查解析器是否为预期的 Cloudflare，而不只看国家或出口 IP。若仍出现本地运营商 DNS，请继续检查模块是否启用及实际 DNS 日志；关闭兼容模式不保证覆盖所有隧道外流量。
